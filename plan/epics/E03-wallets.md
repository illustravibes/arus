# E03 — Wallet dan Kategori

**Fase:** 1 / MVP

## Deliverables

- S-20 sampai S-23 dan S-40 sampai S-42.
- Wallet bank/e-wallet/cash/credit, initial balance, archive, sort order.
- Category income/expense datar dan system category yang terlindungi.

## Acceptance criteria

- Wallet dengan history tidak dapat dihapus.
- Archive menghilangkan wallet/category dari input baru tanpa merusak history.
- Kredit memvalidasi field khusus dan menampilkan peringatan limit tanpa memblokir pencatatan valid.
