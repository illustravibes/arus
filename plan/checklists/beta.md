# Beta Checklist

- [ ] Semua MVP acceptance criteria lulus.
- [ ] Dogfood dengan data non-produksi selama periode yang disepakati.
- [ ] Upgrade dari build beta terdahulu dan rollback failure path diuji.
- [ ] Crash/ANR and error triage berjalan tanpa data sensitif.
- [ ] Permission denial, offline mode, restart proses, dan low storage diuji.
- [ ] Aksesibilitas dan perangkat fisik minimal diuji.
- [ ] Known issues dan batasan recovery dikomunikasikan kepada tester.
